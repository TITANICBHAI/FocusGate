Install FocusGate

FocusGate is free. On Firefox and Edge, add it from the official add-on store. On Chrome, install it from the GitHub release in five short steps.

  • Firefox
  • Edge
  • Chrome
  • After you install

Firefox

Firefox 140 or later. Firefox for Android 142 or later.

  1. Open the add-on page

    FocusGate on Firefox Add-ons.

  2. Add it

    Choose Add to Firefox and accept the permission prompt.

  3. Allow access to sites

    FocusGate needs site access to block pages. If blocking does not work, open about:addons, choose FocusGate, open Permissions and allow access to your data for all websites.

  4. Open it

    Click the FocusGate toolbar button. On desktop it opens in the sidebar. On Android there is no sidebar, so it opens in a tab.

Add to Firefox

Microsoft Edge

Installs from Microsoft Edge Add-ons and updates itself.

  1. Open the add-on page

    FocusGate on Microsoft Edge Add-ons.

  2. Get it

    Choose Get, then Add extension.

  3. Open it

    Click the FocusGate icon in the toolbar (or under the puzzle-piece Extensions menu) to open the side panel.

Add to Edge

Chrome

FocusGate is not on the Chrome Web Store, so Chrome installs it from the GitHub release. It is the same extension. Chrome 116 or later.

  1. Download the extension

    Get focusgate-chrome.zip from the latest GitHub release. Download focusgate-chrome.zip, or open the Releases page and pick it from the list of files.

  2. Extract it to a folder you will keep

    Extract the zip to a permanent place, such as Documents/FocusGate, not your Downloads folder. Chrome loads the extension from that folder every time it starts, so don't move or delete it. Open the folder and check that manifest.json is directly inside; if the zip made an extra folder, use the inner one.

  3. Open the extensions page

    In Chrome, go to chrome://extensions and turn on Developer mode (top right).

  4. Load it

    Choose Load unpacked and select the folder that contains manifest.json. FocusGate appears in your list of extensions.

  5. Pin it and open it

    Click the puzzle-piece icon in the toolbar and pin FocusGate. Click its icon to open the side panel. A guided setup opens the first time.

Download focusgate-chrome.zipAll releases

Keep the folder where it is

Chrome runs an unpacked extension from its folder. If you move or delete the folder, the extension stops working.

Back up before you move it

An unpacked extension's data belongs to the folder it was loaded from. Before moving it or loading it from a new place, open Settings and export a backup, then import it afterwards.

Updating

Chrome does not update this install for you. Download the new zip, replace the files in the same folder, then press the reload button on chrome://extensions. Export a backup first to be safe.

Other Chromium-based browsers may load the same file in the same way. Only Chrome, Edge and Firefox are supported. On Edge you can also load focusgate-edge.zip from the release as an unpacked extension, but the Edge Add-ons store is the easier route.

After you install

You can be blocking in about a minute.

  1. Run the guided setup

    It opens the first time. You can run it again from the You tab.

  2. Add the sites that distract you

    On the Focus tab, choose Add sites. Add keywords and schedules from the Rules tab or the full-screen dashboard.

  3. Start focusing

    Start a focus session from the side panel or press Alt+Shift+F. Want no way out? Use Block now.
