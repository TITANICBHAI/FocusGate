Chrome installation guide

Bring FocusGate to Chrome.

FocusGate is currently available for Edge and Firefox. You can also run it on Chrome today by loading the extension as an unpacked extension. It takes a few minutes, requires no developer account, and keeps your settings local.

!

Before you begin

FocusGate does not have a Chrome Web Store listing yet. This guide uses Chrome's official Load unpacked option. Only load extension files from a source you trust, and keep the extracted folder on your computer after installing.

0

What you need

Browser

Google Chrome on Windows, macOS, Linux, or ChromeOS.

Extension files

The FocusGate project folder, extracted from its ZIP if necessary.

A permanent folder

Chrome loads the extension from this location, so do not delete or move it afterwards.

1

The full process

Install FocusGate in Chrome

1

Get and extract the extension files

Download the FocusGate source ZIP from the trusted project location, then extract it. If your download is named FocusGate.zip, right-click it and choose Extract All on Windows, or double-click it on macOS and Linux.

Keep the extracted project folder somewhere permanent, such as a dedicated Extensions folder. Do not select the ZIP file itself in Chrome.

2

Open Chrome's extensions page

Open a new Chrome tab and enter chrome://extensions in the address bar. You can also open the three-dot menu, choose Extensions, then Manage Extensions.

3

Turn on Developer mode

Find the Developer mode switch in the top-right corner and turn it on. Chrome will reveal three buttons, including Load unpacked.

4

Load the correct folder

Click Load unpacked, browse to the extracted FocusGate project, and select the folder that contains manifest.json. If Chrome says the manifest is missing, you are one folder too high or too low.

The selected folder should look similar to:

FocusGate/
  manifest.json
  background.js
  content.js
  index.html
5

Pin and open FocusGate

Chrome should show a FocusGate card in your extensions list. Click the puzzle-piece icon in the toolbar, find FocusGate, and click the pin icon so it is always easy to reach. Select the FocusGate shield icon to open its popup and configure your first blocked sites or focus session.

After installation

  • ✓Leave Developer mode enabled while using the unpacked build.
  • ✓Keep the extension folder in place; Chrome reads the extension from that folder.
  • ✓To apply a new version, replace the folder contents and click Reload on the FocusGate card.
  • ✓If Chrome disables it after a browser update, return to chrome://extensions and load or reload it again.

Browser support

FocusGate is prepared for Chrome, Edge, and Firefox. Chrome and Edge use the Chromium package, while Firefox uses the separate Firefox package with Gecko metadata.

For a store installation, use the browser's official extension store. The unpacked process on this page is intended for local testing and development.

Common fixes

Chrome says “Manifest file is missing or unreadable” +

Select the folder that directly contains manifest.json. ZIP files and parent folders containing the project are not valid selections. If the file is present but still fails, download or extract the project again.

The FocusGate icon is missing from my toolbar +

Click Chrome's puzzle-piece Extensions button, find FocusGate, and click the pin. If it is not in the list, check chrome://extensions for an error on the FocusGate card.

The extension shows an error after I moved the folder +

Chrome stores the folder path for an unpacked extension. Put the folder back, or remove the old card from chrome://extensions and use Load unpacked to select its new location.

Chrome says the extension is blocked by an administrator +

Your device or browser may be managed by a school, employer, or family administrator. Only that administrator can allow Developer mode or unpacked extensions. Do not try to bypass an organization policy.
