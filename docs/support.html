Support

Need help with FocusGate?

Use the installation guide for unpacked Chrome and Edge builds. Store users should install and update FocusGate from their browser's extension store.

Report a problem

Include your browser name and version, FocusGate version, the steps to reproduce the issue, and any error shown on the extensions page. Do not include private browsing history or sensitive information.

Open a GitHub issue

Before reporting

  • Confirm the extension is enabled on the browser extensions page.
  • Confirm the site is in your FocusGate rules and the focus mode or schedule is active.
  • Try reloading the extension after installing a new build.
  • Review the Privacy Policy and Terms of Service.
