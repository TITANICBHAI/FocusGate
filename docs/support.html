Support

Need help with FocusGate? Use the install guide for Chrome, Edge and Firefox. Store users should install and update FocusGate from their browser's add-on store.

Before you report a problem

  1. Confirm the extension is enabled on your browser's extensions page.
  2. Confirm the site is in your FocusGate rules and that the focus session, schedule or Block now you expect is active.
  3. On Firefox, open about:addons, choose FocusGate, open Permissions and make sure access to all websites is allowed.
  4. If you installed a new build on Chrome, press reload on chrome://extensions.
  5. Read the FAQ, Privacy Policy and Terms of Service.

Report a problem

Include your browser name and version, the FocusGate version (shown in Settings, in the About card), the steps to reproduce the issue, and any error shown on the extensions page. Do not include private browsing history or sensitive information.

Good to know

  • FocusGate cannot guarantee that every distraction is blocked at all times. Browser updates can occasionally affect blocking.
  • Content filters are Beta. If one stops working after a site redesign, please report it and name the site and the filter.
  • A lock slows you down; it does not make removal impossible.
